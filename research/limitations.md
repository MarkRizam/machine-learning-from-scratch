# Scope, reproducibility and limitations

- This is an educational reproduction, not a novel algorithm or peer-reviewed research result. The protocol was written after initial implementation and correctness tests but before benchmark runs. It is not a registered study.
- Only small synthetic datasets, 3 seeds and the documented configurations were evaluated. These results do not establish performance on real data. Validation sweeps are not unbiased final test performance estimates.
- The comparison does not guarantee equivalent RNG sequences, initialization, tie breaking or tree split search. The forest uses hard class voting rather than the reference forest's averaged probabilities. K-means uses single restarts; differences in random initialization do not demonstrate superior performance. The tree does not split on zero improvement and uses a minimum leaf-size constraint; a separate minimum-split parameter is not provided.
- Linear regression uses NumPy's least-squares solver; least-squares gradient descent is separately available. Logistic regression is unregularized, binary only, with a fixed iteration count. Gaussian NB assumes independent Gaussian features and returns class labels. The optimizer is specific to least squares, not a general callable-objective optimizer. PCA uses SVD; this is not a covariance-eigensolver comparison.
- The library is deliberately small; validation is incomplete for exotic label types, extreme numerical magnitudes and unfitted estimators. It is not a drop-in replacement for scikit-learn. Metrics other than regression and clustering support finite numeric labels, and precision/recall/F1/confusion/log-loss are binary only.
- Local Python 3.13.5, Linux x86_64, NumPy 2.3.5 and scikit-learn 1.8.0 were used. The experiments were repeated with 1e-10 absolute tolerance, zero relative tolerance. Identical runtime or cross-platform bitwise identity is not claimed. A scikit-learn warning about the unregularized logistic configuration was emitted; the numerical test passed.
- No runtime or memory benchmarks, external benchmark dataset or real-world clinical data. No paid services are needed. Dockerfile and CI are provided; Docker and Ruff were unavailable locally, and hosted CI must be checked separately.
- Notebook sources were executed in local Jupyter kernels; after an initial batch interruption, the remaining three completed individually. The subsequent isolated-subprocess runner is supplied for future runs. No full rerun of that revised wrapper is claimed.
